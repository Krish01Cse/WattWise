# Contributing to WattWise

Thank you for your interest in improving **WattWise**! We welcome bug fixes, documentation improvements, dataset additions, and UI refinements.

---

### Code Style & Standards

- **TypeScript**: Strict mode enabled (`noImplicitAny`, strict null checks).
- **Design Language**: Adhere strictly to the cream canvas (`#FCF9F2`), black frames (`#111111`), and electric violet telemetry accent (`#7939E8`).
- **Telemetry Accuracy**: All electrical metering calculations must conform to **IEC 62053-21 Class 1.0/2.0**.
- **Commits**: Follow [Conventional Commits](https://www.conventionalcommits.org/) (`feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `perf:`, `test:`, `chore:`).

---

### Pull Request Process

1. Fork the repo and create your branch from `main`.
2. Ensure `npm run build` succeeds cleanly with 0 TypeScript warnings.
3. Submit your PR with a clear summary of modifications and screenshot if UI changes are included.
