# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.x   | ✅ Yes     |

## Telemetry Bus Isolation & Compliance

- **IEC 62053-21**: Adheres to electrostatic discharge and surge insulation limits for residential static metering.
- **Node Authorization**: Operator credentials and telemetry tokens utilize HMAC-SHA256 authenticated headers.
- **Reporting Vulnerabilities**: Please report sensitive security vulnerabilities privately to `security@wattwise.internal`.
