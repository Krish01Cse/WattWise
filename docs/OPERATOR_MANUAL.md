# WattWise Operator Manual
### Diagnostics & Calibration Operations Guide

---

## 1. Anomaly Response Protocol

### Geyser Nocturnal Continuous Draw
- **Symptom**: Steady 2,000W resistive draw between 01:00 AM and 05:00 AM with zero flow.
- **Intervention**:
  1. Trigger test cycle on Sub-breaker #4.
  2. Inspect thermostat temperature cut-off sensor.
  3. Verify mechanical timer schedule or recirculation loop relay.

### AC Compressor Short-Cycling
- **Symptom**: Compressor duty exceeds 85% with duty cycles < 6 minutes.
- **Intervention**:
  1. Inspect outdoor condenser coil clearance.
  2. Clean evaporator dust filters.
  3. Verify ambient thermostat setpoint is not configured below 24°C.
